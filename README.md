# 🪑 Anjalika Furniture Management System

A **modern, responsive web-based Management Information System (MIS)** designed for **furniture manufacturing and retail operations**.  
Built with **Next.js** and **React.js**, this system streamlines daily business processes from manual paperwork to efficient digital management.

---

## 📋 Overview

**Anjalika Furniture Management System** is a **frontend demonstration project** developed for *Anjalika Furniture* — a small-scale manufacturer and retailer.  
It showcases how a centralized MIS can simplify operations such as product management, order processing, customer tracking, and financial monitoring.

---

## 🌟 Key Features

- 🔐 **Secure Login Interface** – Simulated user authentication  
- 📊 **Real-Time Business Dashboard** – Overview of key performance metrics  
- 🛋️ **Product Catalog Management** – Manage and display wooden furniture items  
- 📦 **Order Processing** – Handle custom and ready-made orders  
- 👥 **Customer Database** – Maintain customer information  
- 📋 **Dual Inventory Tracking** – Monitor both products and raw materials  
- 🚚 **Supplier Management** – Record supplier details and deliveries  
- 💰 **Financial Management** – Manage sales, income, and expenses  
- 📈 **Reports & Analytics** – Visual data insights using charts  
- 📱 **Responsive Design** – Works on desktop, tablet, and mobile

## 🚀 Getting Started

### Prerequisites
- Node.js **v18 or higher**
- npm or yarn

### Installation

bash
# Clone the repository
git clone https://github.com/NavoAma-Perera/Anjalika-Furnitures.git
cd Anjalika-Furnitures

# Install dependencies
npm install

# Run the development server
npm run dev


Open your browser and navigate to:
👉 http://localhost:3000
